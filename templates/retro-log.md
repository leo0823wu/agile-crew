# 回顧紀錄（只在你的電腦、不分享）

每次交付後的團隊回顧在〈回顧紀錄〉最上面加一列（做法見技能 `references/retro.md`）。這份會有專案名稱與使用者原話，所以不放在可分享的技能裡。
開工時 `hooks/session_brief.py` 讀最近 8 列的 ⏳ 帶進對話；結束時 `hooks/stop_gate.py` 檢查 push 之後有沒有改過這份。

**格式（腳本靠它解析，不要改）**：段落標題 `## 趨勢`、`## 回顧紀錄`；每列以 `| YYYY-MM-DD |` 開頭；
「專案／這輪」開頭寫專案名稱（收尾 hook 用它對到專案紀錄）；
「指標摘要」寫 `糾正 N`、`追問 N`、`QA 退回 N`、`重工 N`；待辦寫 `⏳ <一句話>`，多項用「；」分開；
「耗時」先留空，加完這一列跑 `python -I ~/.claude/skills/dev-team/scripts/round_time.py --fill` 自動填（從工作階段紀錄算）。
