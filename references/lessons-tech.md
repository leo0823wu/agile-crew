# 踩過的坑：技術環境（依 `lessons.md` 的關鍵字索引只讀相關段落）

本機電腦（Windows＋Git Bash／PowerShell 環境）、工具、資料庫、框架、外部服務的坑。開工時看這次會碰到哪些技術，只讀那幾段。
新增一列時放進最接近的段落，沒有適合的段落就新增一段並更新 `lessons.md` 的索引。

## T1 Windows 本機、Shell、編碼、Git

PowerShell、Bash、Python、BOM、CRLF、中文路徑、commit

（L-256）要排程的腳本，在排程器裡實跑一次再交付，不要只看直接執行的時間：Windows 工作排程器預設用低優先權跑（CPU 與磁碟都是），同一支腳本直接跑 4.5 分鐘、排程跑超過 12 分鐘還沒完，差點超過設定的時限。做法：`New-ScheduledTaskSettingsSet -Priority 5`（預設 7）、時限給直接執行時間的 10 倍以上、加 `-StartWhenAvailable`（開機時錯過會補跑）；用 `pythonw.exe` 才不會跳黑視窗（這時 `sys.stdout` 是 None，腳本不能假設它存在）。掃大量 JSONL（工作階段紀錄兩週就有幾 GB）時，慢在「整檔轉成文字＋每行都解析」：改用位元組讀（`open(p, "rb")`）、先用 `b'關鍵字' in line` 篩掉用不到的行再 `json.loads`，同樣結果 4.5 分鐘 → 1.5 分鐘；改快前後各跑一次，兩份輸出用 diff 比對要完全一樣。

（L-257）本機 `pip` 本身壞掉（裝的是 Python 預覽版，新版 pip 一啟動就 `InvalidVersion: '0.dev0'`），連 `--no-deps` 都裝不了套件。純 Python 的函式庫不要硬修 pip，改成「放進專案或技能的 vendor 資料夾」：用 PyPI JSON API（`https://pypi.org/pypi/<名稱>/json`）查版本與 sha256，挑發布超過一個月的版本，下載原始檔驗雜湊，Grep 一次有沒有 `socket`／`urllib`／`subprocess`／`exec(` 這類連網或執行外部指令的程式，連同 LICENSE 放進 `vendor/`，腳本開頭 `sys.path.insert` 指過去。好處是免安裝、換電腦（含 Mac）直接能用。下載前照外部資源規則先問使用者。

（L-258）在 PowerShell 跑 `python ... ~/.claude/...`：PowerShell 只在自己的指令（`cd ~`、`Get-Content ~/x`）展開 `~`，傳給外部程式（python、git）的參數原樣送出，python 會把它當成「目前資料夾底下的 `~` 資料夾」而找不到檔。說明文件裡寫的 `~/...` 指令照抄到 PowerShell 一定失敗。做法：PowerShell 一律寫 `"$HOME/.claude/..."`；Git Bash 才能用 `~`。

（L-249）要使用者自己跑、需要輸入密碼的腳本：指令裡有中文路徑時，app 不會出現「執行」按鈕，`run_in_terminal` 也只收 ASCII，使用者手動複製容易漏參數（曾回報「跑完了」但其實沒跑）。做法：在 ASCII 路徑（例：scratchpad）放一支只轉呼叫的 .sh，用 `run_in_terminal` 開分頁啟動，使用者在分頁裡輸入密碼；跑完用 `read_terminal` 直接讀結果，不再請使用者轉述。
