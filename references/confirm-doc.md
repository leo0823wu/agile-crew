# 給需求方確認的文件（請非技術的人看、做決定、回覆）

只要文件是**要業務主管、需求方看完回覆**的（對照表確認、名單確認、規則確認、資料核對），一律照這份做。
不用等使用者教：這份就是使用者教過的全部（被說「看不懂、不知道要做什麼」三次以上才整理出來，L-183）。

## 一、先問自己四件事

1. 他要**決定**的是哪幾件？（通常只有少數幾題；其他是讓他「有空看」或「備查」）
2. 每一題他做決定**需要看什麼資料**？（放在同一頁、同一列，不要叫他去別頁找）
3. 每一題有哪幾種**具體做法**可以選？（每種都寫清楚會怎麼做，不寫「另一個選項」）
4. 他不同意時**要怎麼寫**？（給選單＋範例，回來我們看得懂、能直接照做）

## 二、Excel 的固定結構（照順序）

| 工作表 | 放什麼 | 他要做什麼 |
|---|---|---|
| **先看這裡** | 這是什麼、為什麼要他看、做錯會怎樣；**要請您做的事**（寫明「只有第 1 項需要回覆」）；**怎麼回覆**（選單怎麼選、選「都不對」時怎麼寫、範例）；名詞說明（例：文件裡的專有寫法） | 讀 |
| **1_請您決定**（必看） | 每列一題：題號、對象、**問題**、**做判斷需要的資料**（例：今年／去年的對照，寫成多行）、**做法①（我們建議）**、**做法②**、**您的選擇**（下拉 ①②③，黃底）、**選 ③ 時怎麼寫（範例）**（灰字，單獨一欄）、**兩個都不對時請寫**（黃底，空白） | 每題選一個 |
| **2_有空看一眼** | 我們判斷「沒十足把握」的明細：只放他看得懂的欄位＋白話判斷理由＋可能有關的資料；最後一欄「您的意見（沒意見不用填；覺得錯請寫○○，例：…）」黃底 | 有空才看，有意見才寫 |
| **3_參考_…** | 很確定的、沒變的、備查用的 | 不用看 |

- **分輕重**：資料多的時候，必看／有空看／不用看三層一定要分，說明頁寫明各幾個。不要一次列幾百列讓人以為全部都要看。
- **要決定的放最前面**，而且判斷需要的資料跟題目在同一列。
- **選項用 ①②③**，不要用 A／B（會跟「A組」「甲組」這類名稱撞）；①② 欄裡寫**具體做法**（例：「A組＝去年的第一組、B組＝…」），不是「照另一個」。
- **範例單獨一欄**：範例放在他要填的格子裡，他沒改的話分不出是範例還是回覆。
- **回覆欄黃底、一題一格**，選單用資料驗證，錯誤樣式設「資訊」（打 1、2、3 或其他字也收）。
- **不放代碼、流水號、欄位名、相似度分數**；判斷理由翻成他的用語。
- **判斷理由要照實寫**：程式裡同一種判定其實包了兩種情況時，先拆開再翻白話（例：「另一類那邊也一樣」跟「依內容挑的、跟另一類那邊不同」不能寫成同一句）。
- 每一頁凍結首列、開篩選、欄寬調到看得到內容、長文字自動換行。

## 三、交件前

1. 跑 `python -X utf8 -I <技能>/scripts/check_plain_doc.py <檔案> --terms <本地>/plain-terms.txt`，要「通過」（說明頁、要他做什麼、分輕重、回覆欄、技術用語、填代碼、選項不具體都會擋）。
2. 自己讀回來一次（程式讀 xlsx 印出每頁前幾列），確認必看那頁每題都有資料、做法①②、選單、範例。
3. 給使用者看時附三樣：檔案、**一句話說明分了哪幾層**、**一段可以直接轉傳的訊息**（下面範本）。文件裡有寫到「之後會怎麼做」這種承諾句，標出來請使用者確認。
4. 回收後：按「您的選擇」逐題照做；③ 的內容看不懂就回頭問使用者，不要猜。

## 四、轉傳訊息範本

> ○○好，附件是〈這份是什麼〉，想請您幫忙確認。**只有「1_請您決定」那頁 N 題需要您回覆**，每題旁邊都有〈判斷需要的資料〉：
> 選 ① 就是照我們的建議、選 ② 是另一種做法（兩欄都寫了具體怎麼做），都不對就選 ③ 在旁邊寫。
> 「2_有空看一眼」有空再看，「3_參考」不用看。填完回傳給我就可以了，謝謝！

## 五、文字檔／訊息版（不是 Excel 時）

同樣順序：開頭三行內寫「要請您做的事」與怎麼回覆 → 必看的題目（每題：問題、資料、做法①②、怎麼回）→ 有空看的 → 備查的放最後或附件。
